# Реестр 57 индикаторов ИАУ с привязкой к функциональным блокам

Сформирован автоматически (`data/build_registry.py`) на основе файла `data/unodc_indicators_raw.csv` — таблицы сопоставления индикаторов с Рамочной статистической моделью UNODC, адаптированной под 7 блоков методики ИАУ.

**Как построена привязка к блокам.** Исходный файл группирует индикаторы по компонентам и аспектам Рамочной модели UNODC (`a.1`, `a.2`, `b.1`, `b.3`, `b.5`, `c.2`), а не по 7 блокам методики ИАУ напрямую. Соответствие установлено по количеству и содержанию индикаторов в каждом аспекте, сверенному с описанием блоков I–VII в главе 3 методики (см. таблицу ниже). Итоговая сумма — 6+8+10+9+7+8+9 = 57 — совпадает с общим числом индикаторов методики, что подтверждает корректность сопоставления. Данное сопоставление желательно верифицировать с автором методики перед утверждением реестра.

**Итого индикаторов:** 57  
**Подтверждена доступность данных в КР:** 0 из 57
